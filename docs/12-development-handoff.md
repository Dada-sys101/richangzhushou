## V1.0 交付目标

为 10–20 名受邀用户交付可安装的 iPhone PWA、电脑网页、管理端和单体 API。主流程包括注册容量控制、基础记账、快捷指令草稿、OCR/文字草稿、日程、待办、提醒、行程、云端同步和离线写入。

## 明确排除

原生 iOS、家庭共享、银行/支付平台自动同步、代付款、复杂智能排程、多人协作、企业功能、微服务和生产部署授权。

## API 与前端联调契约

- OpenAPI 和数据字典先于实现修改。
- API 枚举、数据库枚举和前端显示映射必须一致。
- 所有写接口提供字段错误、权限错误、幂等冲突、版本冲突和服务不可用状态。
- 页面不得依赖未在契约和工作包中声明的字段。

## 第一批可直接创建的任务

1. 初始化独立 Git 仓库和 `codex/*` 功能分支。
2. 创建 npm workspaces 和四个工作区/共享包目录。
3. 固化 Node、TypeScript、格式、Lint 和测试配置。
4. 创建 NestJS 健康检查和 Vue 空壳路由。
5. 创建 Prisma schema 基线与安全 `.env.example`。
6. 将 `docs/06` 端点清单转换为 OpenAPI 3.1 空契约。
7. 建立 CI：安装、格式、Lint、类型、单测、构建、Prisma validate、OpenAPI lint。
8. 创建 WP1 验收报告模板并更新状态文件。
