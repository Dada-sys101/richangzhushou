## 5. 设计约束（不变量与边界）

- 不新增业务功能；复审发现的问题修复限于问题范围，修复后必须复验并更新对应验收记录。
- 以 `docs/09` 质量门槛与 V1 发布验收为完成定义；未验证功能不得写成已验证，计划中的功能不得写成已实现。
- 安全复审基线（`docs/07`）：密码哈希、刷新令牌只存哈希、限流、DTO allow-list、精确 CORS、Helmet、用户范围强制、管理员权限与审计、生产安全错误响应（不泄露堆栈）、日志脱敏（QA-SEC-004）。
- 上传复审基线：限制 MIME/扩展名/大小/魔数；安全随机对象键；防止路径穿越；上传意图过期与一次性令牌；扫描状态门控；失败不产生悬空正式附件（WP4 已实现，本次复审与演练）。
- 可访问性（`docs/08`）：完整键盘路径、可见焦点、语义标签、错误关联；颜色不是状态唯一表达；触控目标舒适可点；200% 缩放下关键操作可达且无必要横向滚动。
- 响应式矩阵：375/390/430/768/1440，覆盖全部页面、主流程、错误状态、离线状态、浏览器 Back、控制台与网络失败（`docs/09` 失败路径）。
- 备份恢复（`docs/10`）：在隔离环境从备份副本恢复数据库并核对数据完整性；migration 采用向前修复优先、破坏性 migration 必须提供备份恢复路径；RPO/RTO 在供应商确定前不虚构。
- 账号删除演练（`docs/10`、`docs/05`）：`DELETION_PENDING` → 期满清理路径；若后台清理尚未实现，必须如实记录缺口，不得伪装为已完成（`[待确认]`）。
- staging 发布清单（`docs/10`）：环境变量、CORS/HTTPS/Cookie 策略、健康检查、部署单元、发布/回滚步骤、监控告警、发布前待确认项；清单与本地演练可产出，真实部署需另行授权。
- 未解决外部项（OPEN-001~011）全部明确记录，不提前宣称“可开放体验”或生产可用。

## 6. Checkpoints（逐个实现并验证）

1. 全量契约与一致性复审：OpenAPI ↔ 数据字典 ↔ Prisma ↔ 前端枚举/类型一致；全量契约测试；文档与代码交叉核对（含 DEC/OPEN 记录）；修复不一致并复验。
2. 安全复审：按 `docs/07` 基线逐项核查（认证/会话/令牌/Cookie、限流、DTO、CORS、Helmet、用户与管理员权限、审计、日志脱敏、错误响应）；发现项修复并复验或明确记录接受理由。
3. 上传复审：附件类型/大小/魔数/文件名/对象键/路径穿越/扫描门控/意图过期/悬空附件清理；本地临时存储演练；修复并复验。
4. 可访问性与响应式：键盘路径、焦点、语义标签、错误关联、颜色非唯一、触控目标；375/390/430/768/1440 + 200% 缩放矩阵（全部页面）；修复并复验。
5. 全量功能回归：`npm run quality`；空库 6 migrations + seed；全量集成测试（WP2–WP7）；浏览器全流程矩阵（全部页面、主流程、错误/离线/Back/控制台/网络失败，覆盖 QA-CAP/SEC/FIN/SC/DRAFT/SYNC/CAL/TASK/REM/TRIP 全量）。
6. 备份恢复演练：数据库备份 → 恢复到隔离临时库 → 数据完整性核对（用户/账单/同步游标/审计等）→ 记录恢复点与结果；migration 回滚/向前修复说明核对。
7. 账号删除演练：申请删除 → `DELETION_PENDING` → 期满清理路径（或如实记录缺口）→ 用户内容与附件清理核对 → 脱敏审计保留核对。
8. 发布准备：staging 发布清单（`docs/10` 落成可执行清单）、隐私说明与小规模试用门槛文档、监控与告警配置清单；文档、状态与 WP8 验收报告（`docs/26-wp8-acceptance-report.md`）同步；记录全部未解决外部项。
