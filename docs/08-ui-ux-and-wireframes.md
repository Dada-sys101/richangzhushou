# 08 UI/UX 与线框规范

文档版本：0.1  
状态：草案  
更新：2026-08-04  
适用版本：V1.0

## 体验原则

- 首屏优先显示今天真正需要处理的内容。
- 新增操作尽量在 1–2 次页面切换内完成。
- AI/OCR 输出使用“待确认”视觉，不与正式记录混淆。
- 金额、时间、同步状态和删除影响始终明确展示。
- 手机端优先单手操作；桌面端优先批量查看和编辑。

## 桌面端结构

```text
┌──────────┬────────────────────────────┐
│ 今日      │ 页面标题 / 搜索 / 同步状态      │
│ 记账      ├──────────────┬─────────────┤
│ 日程      │ 列表或日历       │ 详情/编辑面板   │
│ 行程      │              │             │
│ 我的      │              │             │
└──────────┴──────────────┴─────────────┘
```

## 关键组件

- `QuickCapture`：文字、语音、截图入口。
- `DraftReviewCard`：来源、识别字段、置信提示、确认/丢弃。
- `CalendarView`：按 `Asia/Shanghai` 日期查看日程，新建/编辑/删除/恢复，
  重叠提示与校验错误明确展示。
- `TasksView`：待办列表与状态筛选，完成/取消/编辑/删除/恢复，过期标记。
- `RemindersView`：提醒设置（一次性/日/周/月），取消/重新启用/编辑/删除/恢复，
  通知权限未开启时显示降级提示。
- `TripsView`：行程列表与新建表单（标题/目的地/日期/可选预算），删除/恢复与详情入口。
- `TripDetailView`：行程编辑、服务端费用汇总（实际支出/预算/进度）、节点
  （类型/时间/地点，超范围先确认再保存）、行李清单（勾选/编辑/删除/恢复）、
  行程日期内日历展示与跳转、关联账单入口；错误与网络失败状态明确展示。
- 今日安排卡片：首页聚合今日日程、待办与提醒数量及前三项。
- 最近行程卡片：首页展示最近三个行程并提供 `/trips` 与详情入口。
- `SyncBadge`：已同步、待同步、失败、冲突。
- `MoneyInput`：币种、两位小数、清晰错误提示。
- `RiskConfirmDialog`：展示变更摘要；高风险要求再次确认。
- `CapacityBanner`：管理端展示占用/上限，注册端展示满员。

## 响应式断点与验收宽度

- 移动：375、390、430。
- 平板：768。
- 桌面：1440。
- 200% 缩放不得出现关键操作不可达或不必要横向滚动。

## 状态文案

- 满员：“当前体验名额已满，即使持有邀请码也暂时无法注册。”
- 注册关闭：“当前暂未开放注册，请稍后再试。”
- 离线：“当前离线，新记录将保存在本机并在联网后同步。”
- 冲突：“这条记录已在其他设备修改，请比较后选择保留内容。”
- OCR失败：“暂时无法识别，可以继续手动填写。”

## 可访问性

- 完整键盘路径、可见焦点、语义标签和错误关联。
- 颜色不是状态的唯一表达；金额和同步状态同时使用文字/图标。
- 触控目标至少采用可舒适点击尺寸，避免仅靠悬停。
