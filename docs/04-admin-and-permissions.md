# 04 管理端与权限

文档版本：0.1  
状态：草案  
更新：2026-08-04  
适用版本：V1.0

## 角色

- `USER`：只能访问和管理自己的数据。
- `ADMIN`：管理用户生命周期和系统配置，不默认拥有用户内容读取权。

## 权限矩阵

| 资源/操作 | USER | ADMIN |
| --- | --- | --- |
| 自己的账单、日程、待办、行程 | 读写 | 默认不可读 |
| 其他用户生活数据 | 禁止 | 禁止 |
| 自己的设备、导出、关闭申请 | 读写 | 状态只读或按授权处理 |
| 用户列表与账号状态 | 禁止 | 读写 |
| 邀请码 | 禁止 | 读写 |
| 容量与注册配置 | 禁止 | 读写 |
| 管理审计 | 禁止 | 只读 |
| 系统健康摘要 | 禁止 | 只读 |

## 管理端功能

- `ADM-DASH-001`：显示占用用户数、上限、剩余名额、注册开关和邀请码模式。
- `ADM-INV-001`：创建单次或有限次数邀请码，设置有效期，撤销未用邀请码。
- `ADM-USER-001`：按邮箱脱敏信息、状态和创建时间搜索用户。
- `ADM-USER-002`：暂停、关闭和恢复账号；每次操作必须填写原因。
- `ADM-SET-001`：调整容量上限、注册开关和是否强制邀请码。
- `ADM-AUD-001`：查看管理操作审计，不提供篡改或删除入口。

## 支持访问边界

V1.0 不提供“管理员代用户查看内容”。问题排查优先使用：请求 ID、脱敏错误码、同步状态、记录数量和用户主动导出的诊断包。任何未来支持访问都必须另行设计授权、时限、审计和撤销机制。

## 验收

- 管理员调用用户内容 API 返回禁止或不存在，不因数据库中存在记录而泄露。
- 用户修改 URL、ID 或请求体不能访问他人数据。
- 所有管理写操作生成不可由普通管理员修改的审计记录。
- 管理端不得将密码哈希、会话令牌、快捷指令凭证或完整敏感内容返回前端。
