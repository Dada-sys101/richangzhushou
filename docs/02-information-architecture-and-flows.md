## 用户端导航

| 一级入口 | 页面 |
| --- | --- |
| 今日 | 今日概览、快速录入、待确认记录、同步状态 |
| 记账 | 账单列表、账单表单、截图识别、预算、统计 |
| 日程 | 日历、日程详情、待办列表、提醒设置 |
| 行程 | 行程列表、行程详情、节点、行李清单 |
| 我的 | 资料、分类账户、快捷指令、设备同步、导出、关闭账号 |

移动端使用底部五项导航和全局“+”；桌面端使用侧边导航和更宽的列表/详情布局。

## 管理端导航

- 仪表盘：有效用户、容量、剩余名额、注册状态。
- 邀请码：创建、撤销、过期、使用记录。
- 用户：状态、容量占用、暂停、关闭、恢复。
- 系统设置：容量上限、注册开关、邀请码开关。
- 审计：管理员操作和高风险操作摘要。
- 运行状态：基础健康状态，不展示用户正文。

## 邀请码注册流程

```mermaid
flowchart TD
    A[打开注册页] --> B{注册开关开启?}
    B -- 否 --> X[显示注册已关闭]
    B -- 是 --> C[提交邮箱 密码 邀请码]
    C --> D{邀请码有效?}
    D -- 否 --> Y[显示邀请码错误]
    D -- 是 --> E{有效用户数低于上限?}
    E -- 否 --> Z[显示名额已满]
    E -- 是 --> F[原子创建用户并消耗邀请码]
    F --> G[登录并进入初始化]
```

人数检查、用户创建和邀请码消耗必须处于同一数据库事务。

## 快捷指令记账流程

```mermaid
flowchart TD
    A[支付后启动快捷指令] --> B[输入或提取金额]
    B --> C[选择分类 可选商户备注]
    C --> D[生成幂等键并提交草稿]
    D --> E{网络可用?}
    E -- 否 --> F[本地保存待同步]
    E -- 是 --> G[服务端返回草稿预览]
    F --> H[联网后重试]
    H --> G
    G --> I[用户确认]
    I --> J[正式入账]
```

## 账号关闭与恢复

```mermaid
stateDiagram-v2
    [*] --> ACTIVE: 注册成功
    ACTIVE --> SUSPENDED: 管理员暂停
    SUSPENDED --> ACTIVE: 管理员恢复且仍占容量
    ACTIVE --> CLOSED: 用户或管理员关闭
    CLOSED --> ACTIVE: 身份验证且容量可用
    CLOSED --> DELETION_PENDING: 申请永久删除
    DELETION_PENDING --> CLOSED: 保留期内撤销
    DELETION_PENDING --> DELETED: 保留期结束并清理
```

## 离线同步流程

1. 客户端生成 `clientMutationId` 和本地记录 ID。
2. 本地立即显示记录为 `PENDING_SYNC`。
3. 联网后提交携带服务端已知版本的变更。
4. 服务端按幂等键去重。
5. 无冲突则返回服务器 ID 和新版本。
6. 有冲突则保存本地草稿并返回服务器当前版本，用户选择保留哪一方或手动合并。

## 通用页面状态

所有核心页面必须提供：首次空状态、加载、提交中、成功、字段错误、权限不足、离线、待同步、同步失败、服务不可用和可重试状态。
