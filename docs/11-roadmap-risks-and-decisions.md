## 风险

| ID | 风险 | 缓解措施 |
| --- | --- | --- |
| RISK-001 | PWA 通知在设备、权限和系统策略下不稳定 | 应用内提醒明确状态；V1.1评估原生应用和替代渠道 |
| RISK-002 | Apple Wallet 触发器不保证提供完整金额/商户 | 快捷指令主动询问并预览确认，不承诺全自动 |
| RISK-003 | 语音/文件导入格式多样导致误识别 | 只生成草稿；字段可编辑；保留手动路径（V1 未启用） |
| RISK-004 | 离线同步复杂度超出MVP | 仅同步已定义实体；敏感冲突人工确认；不做通用协作平台 |
| RISK-005 | 账号关闭释放名额后原用户无法恢复 | 关闭前明确提示；恢复不保留名额 |
| RISK-006 | 小用户量下引入过多外部服务增加成本 | 所有供应商适配、可禁用、可回退手动流程 |
| RISK-007 | 管理排障与隐私边界冲突 | 使用脱敏诊断、请求ID和用户主动导出，不默认开放正文 |

## 变更控制

涉及资金计算、账号容量、权限、数据保留、第三方数据采集或基础设施成本的变更，必须先更新规则、数据、API、测试和风险文档，再进入实现。
