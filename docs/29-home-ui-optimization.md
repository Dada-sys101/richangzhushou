# 首页界面优化（docs/29）

文档版本：1.0
状态：已完成本地验证（未提交、未推送、未部署）
更新：2026-08-06

## 任务目标

将用户端首页从功能原型优化为清晰、现代、适合日常使用的个人助手首页；
仅改动前端展示与交互层级，不修改后端接口、OpenAPI 契约、数据库或核心业务逻辑。

## 修改文件

### 新增

- `apps/web/src/components/AppIcon.vue`：统一线性图标组件（无第三方图标库）。
- `apps/web/src/components/SiteHeader.vue`：顶部导航（首页/日程/待办/财务/行程/更多 + 同步徽章）。
- `apps/web/src/components/BottomNav.vue`：移动端底部导航（首页/日程/记一笔/待办/我的）。
- `apps/web/src/components/EmptyState.vue`：可复用的空状态卡片。
- `apps/web/src/views/HomeView.test.ts`、`SiteHeader.test.ts`、`BottomNav.test.ts`、`SyncBadge.test.ts`。

### 修改

- `apps/web/src/views/HomeView.vue`：首页重写。
- `apps/web/src/App.vue`：接入 SiteHeader / BottomNav，移除旧导航。
- `apps/web/src/router.ts`：未登录访问首页时不再强制跳转登录页，改为展示首页登录提示。
- `apps/web/src/api/client.ts`：新增 `apiErrorKind` 错误分类（401 = 登录失效）。
- `apps/web/src/stores/finance.ts` / `planner.ts` / `trips.ts`：记录 `errorKind`，供首页区分登录失效与普通请求失败；`loadFinanceData` 的账单列表不再按所选月份过滤（首页“最近账单”展示最近记录）。
- `apps/web/src/components/SyncBadge.vue`：状态文案更新为已同步/同步中/同步失败/有冲突。
- `apps/web/src/offline/sync.ts` 与 `stores/sync.ts`：暴露 `isSyncing`，支持“同步中”状态。
- `apps/web/src/styles.css`：设计变量、浅灰蓝背景、白色卡片、统一圆角/边框/阴影、1280px 容器、响应式与底部导航样式。
- `apps/web/src/views/AccountView.vue` / `AccountsView.vue`：“个人设置”与“资金账户”标题。

## 实施内容

### P0

1. 首页不再直接展示后端技术错误文本。
2. 认证异常转换为友好状态：
   - 未登录：请登录后查看今日数据（登录按钮）；
   - 登录失效（401）：登录状态已过期，请重新登录（重新登录按钮）；
   - 请求失败：数据加载失败，请稍后重试（重试按钮）。
3. 首页标题改为“今日概览”，副标题显示当前日期。
4. “资金账户”“个人设置”术语替换完成。
5. 顶部导航精简为：首页、日程、待办、财务、行程、更多。
6. 快捷记录、草稿中心、快捷指令、提醒、预算、分类、资金账户、个人设置（及有冲突时的同步冲突）收进“更多”。

### P1

7. 首页快捷操作仅保留：记一笔、新建待办、新建日程、添加提醒，均带统一线性图标。
8. 今日安排卡片保留日程/待办/提醒，增加说明文字与“查看全部”入口。
9. 新增“本月财务”摘要卡片：收入、支出、预算剩余（含预算进度与去设置入口）。
10. 最近账单/最近行程空状态增加图标、说明与操作按钮。
11. 同步状态支持已同步、同步中、同步失败，失败时提供重试。

### 视觉与工程

12. 浅灰蓝页面背景、白色内容卡片；统一圆角/边框/阴影/字体间距；内容最大宽度 1280px 并居中。
13. 首页仪表盘仅保留一个主要深蓝色操作入口（移动端底部“记一笔”）；其余操作使用中性次级样式。
14. 品牌主色保持 `#2563eb`，无复杂渐变；375/390/430/768/1440 无横向溢出。
15. 移动端底部导航：首页、日程、记一笔、待办、我的；顶部保留“更多”入口以访问次级功能。
16. 未引入重量级 UI 框架；图标为项目内组件。

## 顺带修复

- 首页“今日安排”中本地 IndexedDB 缓存日程未按日期过滤的既有缺陷：`planner.loadCalendarEvents` 现在对本地缓存按上海时区当日边界过滤（与后端 `dayBounds` 语义一致），离线路径同样生效。
