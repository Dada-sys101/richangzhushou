## 强制验收场景

### 注册和容量

- `QA-CAP-001`：上限20、占用19时，一个有效邀请码注册成功。
- `QA-CAP-002`：占用20时，有效邀请码返回 `CAPACITY_REACHED` 且不消耗次数。
- `QA-CAP-003`：两个并发请求争抢最后名额，仅一个成功。
- `QA-CAP-004`：关闭 ACTIVE 用户后容量立即减一，会话失效。
- `QA-CAP-005`：关闭用户在容量满时恢复失败且仍为 CLOSED。
- `QA-CAP-006`：SUSPENDED 用户仍占容量。

### 数据隔离和权限

- `QA-SEC-001`：用户 A 使用用户 B 的资源 ID 得到 404，不能观察存在性。
- `QA-SEC-002`：管理员默认不能调用用户账单、日程、待办和行程正文 API。
- `QA-SEC-003`：邀请码、刷新令牌和快捷指令凭证数据库均无明文。
- `QA-SEC-004`：日志不含密码、令牌、完整邮箱和用户正文。

### 记账和快捷指令

- `QA-FIN-001`：0.1+0.2 等金额累计无浮点误差。
- `QA-FIN-002`：退款正确冲减支出且不使用负数绕过类型。
- `QA-SC-001`：同一幂等键重复提交只生成一个草稿。
- `QA-SC-002`：相同幂等键不同内容返回冲突。
- `QA-SC-003`：撤销设备凭证后快捷指令立即不可写。

### OCR、AI与确认

- `QA-DRAFT-001`：OCR失败仍可手动完成账单。
- `QA-DRAFT-002`：未确认草稿不进入正式统计。
- `QA-DRAFT-003`：批量删除和关闭账号需要二次确认并生成审计。

### 离线同步

- `QA-SYNC-001`：断网新增账单刷新页面后仍存在待同步队列。
- `QA-SYNC-002`：恢复网络后只生成一条服务器记录。
- `QA-SYNC-003`：两设备修改同一金额返回冲突，不静默覆盖。
- `QA-SYNC-004`：退出或关闭账号后本地敏感缓存与会话清理。

`VERSION_CONFLICT`/`IDEMPOTENCY_CONFLICT`、跨用户 404、管理员 403、限流与

### 日程、待办、提醒和行程

- `QA-CAL-001`：结束早于开始被拒绝；重叠只提示。
- `QA-TASK-001`：完成、延期、取消和逾期计算正确。
- `QA-REM-001`：关闭、暂停或权限撤销的用户不发送提醒。
- `QA-TRIP-001`：关联账单正确汇总行程实际支出。

## 失败路径

必须模拟数据库暂不可用、对象存储失败、OCR/AI超时、邮件失败、通知权限拒绝、网络中断、令牌过期和重复点击。
